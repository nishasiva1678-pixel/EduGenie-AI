# EduGenie AI – Project Development

## 1. Introduction

The Project Development phase involves implementing the EduGenie AI learning assistant based on the requirements and design prepared during the previous phases.

EduGenie AI is an AI-powered learning assistant designed to help students with their academic learning and provide interactive learning support.

## 2. Development Environment

The project is developed using:

- Python
- Visual Studio Code
- FastAPI
- Google Gemini API
- HTML
- CSS
- Git and GitHub

## 3. Project Structure

The project consists of the following major files and folders:

| File/Folder | Description |
|---|---|
| `main.py` | Main application file |
| `qna.py` | Question and answer functionality |
| `explanation_module.py` | Provides topic explanations |
| `learning_path.py` | Provides learning path recommendations |
| `quiz_module.py` | Generates quizzes |
| `summary_module.py` | Provides text summarization |
| `templates/` | Contains HTML files |
| `static/` | Contains CSS files |
| `requirements.txt` | Contains required Python packages |

## 4. Development Process

The development process includes:

1. Setting up the Python environment.
2. Creating the application structure.
3. Developing the main application.
4. Developing individual learning modules.
5. Creating the user interface.
6. Integrating the AI functionality.
7. Implementing learning features.
8. Testing the application.
9. Fixing errors and improving functionality.

## 5. Main Application

The `main.py` file acts as the main application file.

It manages the FastAPI application and connects the different modules used by EduGenie AI.

## 6. Learning Modules

EduGenie AI contains several modules to support different learning activities.

### Question and Answer

The `qna.py` module handles question-and-answer functionality.

### Topic Explanation

The `explanation_module.py` module provides explanations for learning topics.

### Learning Path

The `learning_path.py` module provides learning path recommendations.

### Quiz Generation

The `quiz_module.py` module supports quiz generation for learning and practice.

### Summarization

The `summary_module.py` module provides summarization functionality.

## 7. User Interface

The user interface is developed using HTML and CSS.

The `templates` folder contains the HTML interface, while the `static` folder contains the CSS styling.

## 8. Technology Integration

The project uses AI technology to provide intelligent learning assistance.

The application processes the student's request and generates appropriate learning support through the integrated AI functionality.

## 9. Error Handling

The application is designed to handle common errors such as:

- Invalid user input
- Empty input
- API-related errors
- Internet connectivity problems
- Unexpected application errors

## 10. Security

Sensitive information such as API keys should not be uploaded to the public GitHub repository.

API credentials should be stored securely using environment variables or other appropriate methods.

## 11. Development Outcome

The development phase produces a working version of the EduGenie AI application with multiple learning features, including question answering, explanations, quizzes, summaries, and learning path recommendations.

## 12. Conclusion

The Project Development phase converts the requirements and design of EduGenie AI into a functional application.

The developed system provides students with an AI-powered learning environment that supports different academic learning activities.
