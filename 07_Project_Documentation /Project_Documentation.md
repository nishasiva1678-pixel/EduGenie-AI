# EduGenie AI – Project Documentation

## 1. Project Overview

EduGenie AI is an AI-powered learning assistant developed to support students in their academic learning activities.

The system provides interactive learning features such as question answering, topic explanations, quiz generation, text summarization, and learning path recommendations.

## 2. Problem Statement

Students may face difficulties in understanding academic topics, finding suitable explanations, preparing for quizzes, and organizing their learning activities.

EduGenie AI is developed to provide students with an interactive and intelligent learning assistant in one platform.

## 3. Objectives

The main objectives of EduGenie AI are:

- To provide AI-based answers to student questions.
- To explain academic topics in an understandable manner.
- To generate quizzes for practice.
- To summarize learning content.
- To provide personalized learning path recommendations.
- To provide a simple and user-friendly learning interface.

## 4. Technologies Used

- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- Visual Studio Code
- GitHub

## 5. System Features

### Question and Answer

Students can enter questions and receive AI-generated answers.

### Topic Explanation

The system provides explanations for selected learning topics.

### Quiz Generation

The application can generate quiz questions to help students practice.

### Text Summarization

The system can summarize longer learning content into shorter and useful information.

### Learning Path

The application provides learning recommendations based on the student's learning requirements.

## 6. Project Structure

The project contains the following major components:

- `main.py` – Main application
- `qna.py` – Question and answer functionality
- `explanation_module.py` – Topic explanation
- `learning_path.py` – Learning recommendations
- `quiz_module.py` – Quiz generation
- `summary_module.py` – Text summarization
- `templates/index.html` – User interface
- `static/style.css` – User interface styling
- `requirements.txt` – Required Python packages

## 7. Working Process

The general working process of EduGenie AI is:

1. The student opens the application.
2. The student selects or enters a learning request.
3. The application processes the request.
4. The appropriate learning module is called.
5. AI functionality generates the required response.
6. The result is displayed to the student.
