# EduGenie AI

## AI-Powered Learning Assistant

EduGenie AI is an AI-powered learning assistant designed to support students in their academic learning activities.

The project uses Generative AI technology to provide interactive learning assistance through features such as question answering, topic explanations, quiz generation, summarization, and learning path recommendations.

## Project Objectives

- To provide AI-based learning assistance to students.
- To help students understand difficult academic concepts.
- To provide quick answers and explanations.
- To support interactive and personalized learning.
- To provide multiple learning features through a single application.

## Key Features

- Question and Answer
- Topic Explanation
- Quiz Generation
- Text Summarization
- Learning Path Recommendations
- Interactive User Interface
